# Data Handling with Python

This workspace contains Jupyter notebooks and sample CSV files for learning basic data handling using Python, NumPy, and pandas.

## What this project contains

- `code.ipynb` – Examples of NumPy arrays, array properties, indexing, boolean masking, normalization, and basic pandas operations.
- Sample datasets:
  - `tips.csv`
  - `banklist.csv`

## Topics covered

- Creating and manipulating NumPy arrays
- Array shape, size, dimension, and dtype
- Slicing, fancy indexing, and boolean masking
- Data normalization
- Reading CSV files with pandas
- Viewing and filtering DataFrame data

## Requirements

Make sure you have Python installed along with these packages:

```bash
pip install numpy pandas jupyterlab
```

## How to run

1. Open the folder in Jupyter Notebook or JupyterLab.
2. Launch the environment:

```bash
jupyter lab
```

3. Open one of the `.ipynb` files and run the cells.

## Notes

The notebooks read CSV files from the same workspace folder, so keep the data files in the project directory when running them.

## Purpose

This project is intended for practicing basic Python data handling and introductory data analysis workflows.
